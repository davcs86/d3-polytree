# @d3-polytree/core

Core diagram engine for the d3-polytree v2 ecosystem.

Wires the base canvas (`@d3-polytree/canvas`) and the PFDN model
(`@d3-polytree/pfdn-moddle`) into the `coreModules` didi stack. The `draw`,
`features` and `modelling` layers are carved in from `core-v2beta` incrementally
during Track B / B3.
