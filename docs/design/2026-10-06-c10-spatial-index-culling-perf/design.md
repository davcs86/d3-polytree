## Chosen Approach

C10 (ROADMAP §11, closes H6) ships as **viewport culling that hides an element's paint but keeps its `<g>`**, driven off the zoom transform, over a **pure flat-scan spatial index**, with LOD, and **enforced by deterministic correctness gates plus a blocking frame-time ceiling**. It lands in three PRs: measure → culling → LOD/ceiling.

### 1. Mechanism — "hide the paint, keep the `<g>`" (A′)

- Culling sets one attribute on the element `<g>`: `data-pfd-transient="culled"` (PR3 may also use `"lod"`).
- One CSS rule hides everything in the group except the accessible surface, in a new `packages/interactive-viewer/src/_culling.scss` (imported from `style.scss`, beside `_outline.scss` / `_focus.scss`):
  `.pfdjs-container .element[data-pfd-transient] > :not(title):not(desc) { display: none }`
- The `<g>` itself is never `display:none`, so its `<title>`, `<desc>`, `tabindex` and focusability stay: **off-screen elements remain AT-discoverable (user decision: not waived)**. Hidden: `.innerElement`, the outline rect, the focus ring, `.resize-container` + corners, a zone's direct-child `<rect>`, and anything Outline/keyboardNav/Editor add later (no paint-target capture needed).
- Nothing is removed: registries (`DrawingRegistry.ts:4-22`, `ElementRegistry`), `.created/.removed` events, selection (`selection.ts:31`), keyboardNav `_entries` (`keyboardNav.ts:50`), SearchPanel (`SearchPanel.ts:111`), alertIcons (`alertIcons.ts:63`), mouseEvents listeners and drag's label lookup (`drag.ts:195-209`) all stay valid (recon residency table).
- `visibility:hidden` and `display:none` on the whole `<g>` were rejected: both drop the element from the accessibility tree.
- **CSS fail-open + self-check.** If the stylesheet is absent nothing hides (perf loss only). After the first hide pass, read `getComputedStyle(<first hidden child>).display`; if not `'none'`: if `document.readyState !== 'complete'` re-check on window `load` (or next rAF if already complete); a failure at/after `complete` is definitive → remove all attributes, `active=false`, `console.warn` once. Never reachable in jsdom/ssr (inert before any hide).

### 2. Index — pure, DOM-free, `packages/core/src/spatial/` (`route/`-style, `route/index.ts:1-8`)

- Seam used by the shipped path: `upsert(id, bounds)` (returns the stable slot index), `remove(id)`, `scan(viewportRect, visit(slot, inside))` — a two-sided classification feeding both passes. A query/grid/quadtree variant is built **only** on a measured trigger (§9). **User waiver (DN-3/DF-2): ROADMAP's "quadtree" is narrowed to a flat scan behind this seam.**
- `FlatIndex`: typed-array bounds; id→slot `Map` used for lookup only, never iterated to produce output (PLAT-06, `docs/context-constitution.md:29`); tombstone on remove, revive/append on create.
- `elementBounds(kind, def)` → `{x0,y0,x1,y1}` from **model geometry only** (jsdom-safe; `definitions.ts:9-44`), world units: node `[x−3, x+size+9]`; link waypoint AABB ± `(4.5·lineWidth+2)`; zone `position+(w,h) ± border.lineWidth/2`; label (no w/h in the model) `w = max(1,len)·fontSize·1.2 + 3.66 + 6`, `h = fontSize·1.5 + 3.66 + 6`. Direct property reads only (never `.get()` on isMany — ledger 2026-09-20); **any non-finite bound ⇒ always visible, never culled**. A new rect type is justified because `route/types.ts:19-24` `Obstacle` is square-only (DN-2). Exported from `core/src/index.ts`.

### 3. `Culling` feature — `packages/core/src/features/culling.ts`

- Outline-shaped (`outline.ts:25-96`): `static readonly $inject = ['canvas','eventBus','d3polytree','d3polytree.definitions.settings.zoom']`; module `{ __init__:['culling'], culling:['type', Culling], __depends__:[zoomModule] }` (Axes pattern, `features/index.ts:98-102`; PLAT-02).
- Registered in `InteractiveViewer.interactionModules` **immediately before `outlineModule`** (`interactive-viewer/src/index.ts:44-61`): ahead of the drawers (sees every boot `.created`; DI invariant 2) and ahead of Outline (reveal-before-measure). `getModules()` is unchanged, `domNotificationsModule` stays last (PLAT-01). Editor inherits via the spread (`editor/src/index.ts:182-193`); the static `Viewer`/ssr never load it.
- Subscribes `<cls>.created/.updated/.removed/.moving`, `canvas.zoomed`, `canvas.resized`, `d3canvas.destroy`. (**No `d3canvas.clear` subscription**: it only emits, nothing is removed, resetting slots would orphan hidden `<g>`s.)
- `.created` is an **idempotent upsert** that resets the slot to visible and binds the NEW `<g>` (undo/redo re-creates ids: `commands.ts:73-79`). `.removed` reads only `def.id` (bare `{id}`, `BaseElement.ts:99-101`; ledger c2). `.updated`/`.moving` refresh bounds and mark `slotsDirty`.
- **Reveal-before-measure: `label.created` and `label.updated` only.** Outline's `getBBox` (`outline.ts:55-59`) is the only consumer; zones' `.innerElement` is empty (`Zones.ts:36-43`) so zone reveal would be dead code. Handler removes the attribute, sets `slot.culled=false`, `slotsDirty=true`. Test registration order Culling-before-Outline (eventemitter3 preserves it) by stubbing `getBBox` and asserting `closest('[data-pfd-transient]') === null` at call time.
- **Viewport** from persisted `settings.zoom` (`zoom.ts:94-98`, written before `canvas.zoomed` at `:100`, only while `_isZoomable`) via direct property reads — not `canvas.getTransform()` (allocates a `<g>` per call, identity in jsdom; `Canvas.ts:105-119`). Missing/non-finite ⇒ fail open (show all). Size from a `ResizeObserver` on `canvas.getContainer()` (`Canvas.ts:78`), created at construction, guarded by `typeof ResizeObserver`; `getSize()` only as fallback when no RO exists.
- **Passes.** SHOW is **synchronous** in the `canvas.zoomed` / RO handler (typed-array scan; removes the one-frame lag a rAF-requested show has during d3-transition zoom). The rAF pass (ONE per dirty burst, coalesced) is **stateless and two-sided**: show slots inside the padded viewport, hide slots outside — using the CURRENT viewport/slot state, so a deferred hide can never target a re-entered element. Skip iff `!viewportDirty && !slotsDirty && backlog === 0`. Writes are O(changes); an unchanged flush performs zero writes and zero allocations (ledger c14).
- **Pad**: single pad, world units: `ceil(max measured overhang of painted extent over indexed bounds, across classes in G1) + 1` (expected single-digit px); no velocity term while SHOW is synchronous.
- **Inert**: `.created` checks only `slotCount ≥ CULL_MIN_ELEMENTS` (provisional 1000, `@internal` export, tuned by PR1). Size > 0 is read in the RO/rAF callback. jsdom/vitest and ssr (`pretendToBeVisual`, `ssr/src/dom.ts:23`) DO have rAF — only size==0 / no `ResizeObserver` make them inert. Inert checks precede `requestAnimationFrame`; capture `{id, cancel: globalThis.cancelAnimationFrame.bind(globalThis)}` at schedule time; all callbacks begin `if (this._destroyed) return`. Teardown on `d3canvas.destroy` (`Diagram.ts:75` → `Canvas.ts:66,70`; VIEWER-01): cancel rAF, `ResizeObserver.disconnect()`, `destroyed = true`, remove the idle attribute. No `setTimeout`.
- **Idle signal**: `data-pfd-culling-idle="true|false"` on the canvas **container div** (outside the `<svg>`, so never exported; `Canvas.ts:88-90`). `"false"` is written synchronously in every handler that marks dirty; `"true"` only when no rAF is pending and nothing is dirty; absent until activation and in jsdom/ssr.
- **Activation**: `culling?: boolean` typed in `ViewerOptions` (`viewer/src/index.ts:53-65`), default **on**, read via `'d3polytree'` options. No modes, no `disable()` (user decision); the option is the kill switch.
- LOD (PR3): labels hidden below a zoom threshold (provisional 0.3, `tooltip.ts:11,42` precedent) via the same attribute; the outline hides with it so an invisible label cannot intercept pointer events. A selected label hidden by LOD loses its visible outline (documented).

### 4. Accessibility (non-waived)

- The `<g>` + `<title>`/`<desc>` + tabindex survive culling; a culled label's `<text>` leaves the AX tree, so `<title>` is the AT-visible name.
- **N1 (approved): refresh `<title>` in `BaseElement.updateElement`** (written once today at `BaseElement.ts:128-129`): recompute `_accessibleName(def)` (`BaseElement.ts:108-116`; a label's name is `label: <text>`) and write it via `element.selectChild('title')` (d3-selection v3 — confirm against lockfile; not `:scope`, not `:first-child`, which Outline displaces `outline.ts:68-70`) only when it differs. `<desc>` is the immutable id. Verify ssr goldens / VR / `a11y-baseline.json` are unaffected (boot goes through create).
- keyboardNav needs no change: `_focus` focuses a never-hidden `<g>` (`keyboardNav.ts:216-218`). The roving focus ring is a hidden child while its element is culled; keyboardNav never pans — unchanged from today in practice (culled = outside viewport + pad).

### 5. Export

- `getSvgString` clones the live DOM (`SvgExportingUtils.ts:14`); the clone-only strip removes `[data-pfd-transient]` right after cloning (canvas stays ignorant of culling: it exports the marker-name constant, core imports it). Culled elements export fully painted.
- **Honest scope:** `getCSSStyles` (`SvgExportingUtils.ts:33-74`) inlines any rule whose selector contains `[sels].<cls>[sels]` for a live class — the new rule IS inlined into every in-browser export (inert after the strip; same class of leak as `.element > .element-outline`; no colours/tokens → theme-invariance intact). G5 is therefore **culling-on vs culling-off byte parity in the same browser**, not "identical to today" in browsers. jsdom/ssr have no stylesheets → unchanged. `packages/element/src/styles.generated.ts` is regenerated in the same PR (PLAT-04; `ci.yml:40-51` drift gate).

### 6. Palette fix (introduced bug)

`BaseAddHandler._calculatePosition` (`BaseAddHandler.ts:35-52`) reads `getBoundingClientRect` of `drawingRegistry.getAll()[0]`, which is empty when that element is culled. New: `x = (cw/2 − tx)/k`, `y = (ch/2 − ty)/k` from `getSize()` + the persisted viewport. Differs from the old result by the reference element's `localLeft` ≤ ~3–4 world px (**N2, accepted**). PR2 probe: old vs new at 3 zooms × 3 pans `|Δ| ≤ 4`, and a culled `elements[0]` does not change the result.

## Rejected Alternatives

- **Remove culled `<g>` from the DOM** — breaks every residency assumption (selection, keyboardNav `_entries`, drag label lookup, SearchPanel, alertIcons) and the `.removed`/announcer semantics; needs a re-create path and a bare-`{id}` trap (ledger c2).
- **`visibility:hidden` or `display:none` on the whole `<g>`** — both remove the element from the accessibility tree (violates the non-waived AT decision); `display:none` additionally zeroes `getBBox` for Outline.
- **Per-child `display="none"` attributes** — ~5 writes/element, clobbers existing inline `display`, needs per-child export undo, and re-introduces paint-target capture (zone rect ambiguity).
- **Injected `<style>` instead of an SCSS rule** — breaks under a CSP without `unsafe-inline`, doesn't reach the element package's shadow root, duplicates per instance.
- **Hand-written or `d3-quadtree` quadtree now** — a flat scan over ~23k slots is estimated well under the frame budget (unverified until PR1); `d3-quadtree` is point-only and not a core dependency. Kept behind the `scan` seam, promoted by §9 triggers. (User waiver.)
- **Canvas overlay now** — no `<canvas>` precedent, a11y or determinism rule; deferred behind measurement (user waiver).
- **Rolling culling into a pin set** (selected/focused/drag ids never culled) — protected only the remove-based variant; unneeded when the `<g>` stays resident.
- **`off`/`auto`/`on` modes, `disable()`, `PERF_GATE=report|enforce`** — speculative config (DN-7); replaced by one boolean and a blocking gate.
- **Ratio gate (`median(on) ≤ R × median(off)`)** — circular (≈1.0 if hiding saves only paint) and blind to equal regressions in both arms; informational at most.
- **rAF-deferred SHOW** — systematic one-frame lag during d3-transition zoom and under dropped frames; replaced by synchronous SHOW.
- **Dual-pad hysteresis, epoch stamps, `_hideCursor`, free-list, Editor perf arm, file-allowlist tripwire** — dropped from the default build (DN-7); promoted only on §9 measurements, tripwire dropped outright (ledger 2026-09-17).
- **Scoped reroute / hoisted obstacle list / Worker offload** — out of scope (user decision, no metrics).
- **Per-frame `d3canvas.clear`/zone reveal handlers** — dead code / semantically wrong (orphans hidden `<g>`s); removed.
- **Default-off first release with a flip PR** — defers all C10 value; replaced by default-on + count-threshold inertness (user decision).

## Open Risks

- [ ] Whether the blocking frame-time ceiling is stable on shared runners — to be settled by PR1 separation/spread data; PR2 returns to the user if separation < 2× spread (§7). The user accepted the flaky-red risk of "blocking from day one".
- [x] P1 (does a `<g>` with `<title>` and all-`display:none` children keep its AX name?) and P3 (`focus()` on it) — **verified 2026-10-07 in Chromium** (CDP AX tree unchanged, group name retained; `activeElement` lands on the culled `<g>`); PR1 keeps them as regression guards; the `aria-label` mirror remains only a contingency if a later browser/Chromium change breaks it. Chromium only is gated; Firefox/WebKit and real AT are not CI-gateable (C2.a).
- [ ] No-CSS consumers (core without `interactive-viewer/style.css`, stale `styles.generated.ts`) lose the perf win after one warning; real-cascade self-check covered only in the browser lane.
- [ ] A culled label's `<text>` is absent from the AX tree; `<title>` (refreshed per N1) is the only AT text.
- [ ] Scan cost per `canvas.zoomed` event, first big hide pass, d3-timer-in-rAF — unmeasured until PR1; the update-from-d3-timer-rAF case can show one frame of culled content.
- [ ] Label width estimate (`fontSize·1.2` per char) is unproven for every font — G1 enforces it for the fixture fonts.
- [ ] Live-resize stale bounds (P4); whether the resize target is selected during the gesture is unverified.
- [ ] `<title>` refresh may alter ssr/VR output for diagrams with stale titles — verify by running both suites in PR2.
